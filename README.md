# لوحة التحكم | الذكاء الاصطناعي في إنتاج الأنظمة الإلكترونية
### Course Control Panel - AI in Electronic Systems Production

موقع متكامل باللغة العربية مخصص لإدارة وتتبع الحضور والغياب، التقييمات والأكاديمية، المحاضرات والواجبات، وحلبة المنافسة المباشرة (Battle Mode)، مع نظام أوسمة ودروع تفاعلي (Gamification).

---

## 🌟 المميزات الرئيسية

### 1. الخط والتصميم والـ UX (Design System)
- **الخط المستخدم**: خط **IBM Plex Sans Arabic** الأصلي عبر Google Fonts.
- **واجهة المستخدم**: متناغمة بالكامل بنمط **Dark Obsidian & Neon Cyan Glassmorphic** مع دعم كامل للغة العربية (RTL).
- **تجربة المستخدم (UX)**: تنقل سريع، إشعارات تفاعلية (Toasts)، ماسح ضوئي للكاميرا، ومؤثرات احتفالية (Confetti).

### 2. جانب المعلم (Teacher Side)
- **تسجيل وإدارة الطلاب**: إضافة طالب جديد بالاسم، الرقم الأكاديمي (ID)، كلمة المرور، العمر، الصورة الشخصية، مع **توليد تلقائي لكود QR رمز استجابة سريعة** يحمل بيانات الطالب.
- **بطاقات الطالب القابلة للطباعة**: إمكانية استعراض وطباعة بطاقة تعريفية ذكية تحتوي على كود الـ QR لكل طالب.
- **إدارة المجموعات والشُعب**: تنظيم الطلاب في مجموعات مخصصة (مثل: شُعبة الذكاء الاصطناعي، شُعبة الأنظمة المدمجة).
- **نظام تتبع الحضور والغياب**:
  - تسجيل يدوي أو سريع بضغطة زر.
  - **ماسح ضوئي مدمج عبر الكاميرا (Live QR Code Scanner)** لتسجيل الحضور بمجرد مسح كود بطاقة الطالب!
- **إدارة المحاضرات**: رفع وتنسيق وحدات المقرر والشرائح التعليمية.
- **إدارة الواجبات والمهام**: إسناد مشاريع الدوائر الإلكترونية والبرمجة للطلاب ومتابعة المواعيد النهائية.
- **حلبة المواجهة المباشرة (Battle Mode)**:
  - اختيار طالبين للتحدي 1v1.
  - طرح أسئلة خيارات متعددة في مجالات الذكاء الاصطناعي ومتحكمات الـ TinyML.
  - احتساب النقاط فورياً وإرسال مؤشرات الفوز مع تحديث نقاط التقييم والدروع تلقائياً.
- **سجل التقييم والدرجات**: تقييم شامل لأداء الطلاب واحتساب التقديرات الأكاديمية (A+, B, C...).
- **نظام الأوسمة والدروع (Gamification System)**:
  - يبدأ كل طالب جديد تلقائياً بـ **الدرع الخشبي 🪵 (Wooden Shield)**.
  - يتطور الدرع تلقائياً كلما ارتفع تقييمه ونقاطه:
    - 🪵 درع خشبي (0 - 500)
    - 🥉 درع برونزي (501 - 1000)
    - 🥈 درع فضي (1001 - 1500)
    - 🥇 درع ذهبي (1501 - 2000)
    - 💎 درع بلاتيني (2001 - 2500)
    - 👑 درع الأسطورة الماسي (2501+)

### 3. جانب الطالب (Student Side)
- **بوابة تسجيل دخول الطالب**: تسجيل الدخول باستخدام الرقم الأكاديمي (Student ID) وكلمة المرور.
- **اللوحة الشخصية**: عرض البيانات الشخصية، بطاقة الـ QR الكود الذكي للحضور، والدرع الحالي مع شريط التقدم للدرع القادم.
- **لائحة الشرف والمتصدرين (Leaderboard)**: ترتيب زملائه بالصف وتطور شاراتهم ونقاطهم الحالية.
- **بطاقات المحاضرات**: تصفح دروس المقرر وتحميل الملفات المرفقة.
- **سجل الحضور والغياب**: استعراض نسبة الحضور الإجمالية ومجموعات الجلسات (حاضر / غائب / متأخر).
- **الواجبات والدرجات**: عرض التقييم الأكاديمي والمهام المكتملة.

## 🚀 طريقة التشغيل المباشر والرفع على Firebase (Firebase Hosting)

### التشغيل المباشر:
يمكن فتح الملف `index.html` في أي متصفح إنترنت (Google Chrome, Edge, Firefox, Safari) مباشرة دون الحاجة لأي خوادم أو تثبيت برامج!

### الرفع والاستضافة على Firebase:
1. تم إرفاق ملفت التهيئة جاهزين داخل المجلد:
   - `firebase.json`
   - `.firebaserc`
2. لرفع الموقع على استضافة Firebase Hosting الخاصة بك، افتح المجلد في موجه الأوامر ثم نفّذ:
   ```bash
   firebase deploy
   ```
3. لإدخال بيانات `firebaseConfig` الخاصة بمشروعك في كود الموقع مباشرة، يمكنك النقر على أيقونة الشعلة 🔥 في الشريط العلوي ولصق كائن التهيئة الخاصة بك.
